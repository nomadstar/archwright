# systemd-timesyncd.service ships with the `systemd` package itself, which
# is present on every Arch system regardless of what packages/*.txt
# declares — deliberately chosen so this file has no dependency on
# packages/official.txt (see docs/decisions/0013-roles-do-not-order-
# against-each-other.md: a service whose unit file is shipped by a
# package this SAME profile declares would be reported as
# status=unresolvable by `plan`, because plan only runs check() for every
# role and never applies anything, so the providing package never actually
# gets installed before the service role looks for its unit file).
#
# Enabling it (never starting it — see
# docs/decisions/0005-no-automatic-removal.md) is a safe, observable side
# effect for the idempotency test: `systemctl is-enabled` flips from
# "disabled" to "enabled" and stays there on a second run.
